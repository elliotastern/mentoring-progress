## Website

Now you are going to set up your website portfolio.

A website is mandatory for those with no data experience and highly recommended for all mentees, as we have found it is a key to getting the best job for our mentees.

### 1. Choose a platform

|  | GitHub Pages | Wix | WordPress | Domain Name + Server | Freelancer-created website (such as Fiverr) |
| --- | --- | --- | --- | --- | --- |
| Cost | Free | $16/month | $30/month | $12/month | ~$300 + $12/month + maintenance costs |
| Time to create the site | None | ~4 hours to format | ~8 hours to pick out your theme and format | Time to create a website from scratch (dependent on skill level) | Time to find a freelancer and for the freelancer to create the site, plus time to maintain the site |
| Customizability | None | Less customizability to do more with your portfolio | High level of customizability | The most customizable option |  |
| Other considerations |  | Your website will stick out more for being unique | Your website will stick out more for being unique |  |  |

### 2. Create the site

For most mentees, the Wix option is recommended.

- **Option 1 (recommended):** Get a copy of the Wix website to use as a template
- **Option 2:** Create a website yourself

See this doc for more details: [BONUS: Personal Website Options](https://docs.google.com/document/d/1fiujnr67A95CauvC0k73G0_hgczkI1yBF2h9YstLujA/edit)
