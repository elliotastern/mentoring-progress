# Website

Now you are going to set up your website portfolio

A website is mandatory for those with no data experience and highly recommended for all mentees as we have found it is a key to getting the best job for our mentees**.**

- Choose a platform :

|  | GitHub Pages | Wix | WordPress | Domain Name + Server | Freelancer ; ; (such as Fiverr) ; created website |
| --- | --- | --- | --- | --- | --- |
| Cost | Free | $16/Month | $30/Month | $12/Month | ~$300 + $12/Month + maintenance costs |
| Time to create the site | None | ~4 hours to format | ~8 hours to pick out your theme and format | Time to Create a website from Scratch (dependent on skill level) | Time to find a freelancer and for the freelancer to create the site. Additionally, time to maintain the site |
| Customizability | None | Less customizability to do more with your portfolio | High Level of customizability | The most customizable option |  |
| Other Considerations |  | Your website will stick out more for being unique | our website will stick out more for being unique |  |  |
