  - Data Version Control: Using tools like Git for version control of data pipelines and scripts.
  - Data Quality and Testing: Implementing data quality checks and testing procedures.
  - Monitoring and Logging: Setting up monitoring systems for data pipelines and logging for debugging.
  - Data Security and Compliance: Knowledge of data security practices, GDPR, HIPAA, or other relevant compliance regulations.

  - Docker or any other container platforms

Python does not require you to use objects or classes

Why use OOP in Python:
- Complex programs are hard to keep organized
- OOP structures and organize code
- Easier to maintain and learn
- Groups together data and behaviours in one place
- Promotes modularization of programs
- Isolated programs to allow for the continuation of other parts of your program

- Module vs Package vs Library
- Methods vs functions
