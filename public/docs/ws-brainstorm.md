## Goal

Name **one** primary title and a **10-15 company** list:

| Tier | Count | Meaning |
|------|------:|---------|
| Stretch | ~3 | Dream / harder bar |
| Stepping stone | ~4-9 | Realistic fit |
| Sandbox | ~3 | Practice / easier volume (test methods; rejection is fine) |

Time check: ~30 min for title + top-of-mind list; ~1.5 hrs if you need light research. If it takes much longer, you are overthinking.
