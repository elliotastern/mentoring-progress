# Portfolio Package Guide

**Done when** you have **submitted** all four pieces in the Progress app (Module 3 Exit · Portfolio final). Each Submit saves the link and the date to your login (Firestore in production; local save on localhost). Your mentor can see the dates and links.

## The four pieces

1. **LinkedIn** (profile matches your Job Target title)
2. **Resume** (Google Doc or PDF link)
3. **GitHub** (public profile / best repo)
4. **Personal site** (link to your portfolio home)

## How to submit in the app

1. Open **Module 3 Exit** (Portfolio final), or Module 4 Setup 1: Pre Requirements.
2. Paste each URL. Optional note: Drive / Word / screenshot Doc, or Slack date.
3. Click **Submit** on each piece, or **Submit all four** when every URL is filled.
4. Re-submit anytime to update the link and refresh the date.

Fastest capture: [Awesome Screenshot](https://www.awesomescreenshot.com/) (Chrome). Capture LinkedIn, resume, GitHub, and your site, put images in one Google Doc / Word file, then paste that Doc link as the URL or note for each piece (or once in notes).

## Checklist

- [ ] LinkedIn submitted (date shown in app)
- [ ] Resume submitted (date shown in app)
- [ ] GitHub submitted (date shown in app)
- [ ] Personal site submitted (date shown in app)
- [ ] Job Target title matches LinkedIn headline and resume summary

## Where this gates Job Search

Module 4 Setup 1 shares this prereq: **Portfolio final submitted**. That checkbox turns on only after all four pieces have submit dates (not just from reading Module 3 guides).
