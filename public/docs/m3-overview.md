## Overview: What this module is about

- You will learn how to market yourself
- You will learn how to measure impact and show it
- You will learn how to make a standout portfolio (Resume, LinkedIn, GitHub, Cover letter, etc)

## Takeaways: After you complete this module you should…

- Have a one-page concise, detailed and impactful resume
- Have a LinkedIn page, optimizing every feature for SEO and human readability.
- Learn how to make a standout Github page (portfolio)
- Have a cover letter that tells a good story

## New Habit: Portfolio Touch-Up (30 mins daily)

- Could include:
  - Improving Readme for project
  - Doing an assessment or certification for skills to attach
  - Creating content or writing a blog
  - Post meaningful educational content to an audience below your skill level (ie writing a blog)
  - Make sentences more clear and concise in your portfolio (Resume, LinkedIn, Cover letter, website, etc)
