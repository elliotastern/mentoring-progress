## **Takeaways: **After you complete this module you should…

- Understand what the interviewer is looking for
- Understand how to answer the for most common questions (with a template)
- How to prep for an interview (not your dream job) efficiently
- Understand if you should do a companies assessment/take-home assignment
- How to set up the interview process to have the most leverage
- The importance of asking questions

## New Habit: Interview Prep (~45 mins daily)

- Practicing Screening/Behaviour Interview Questions (15 mins daily)
  - Ask loved ones, friends, roommates, whoever to interview you
  - Do this when you are doing mindless things (E.g. dishes, laundry, etc)
  - Record yourself answer a question (feel free to send it to your mentor for feedback)
- Answering/learning 1-3 interview questions ([sample questions](https://drive.google.com/drive/folders/1iwFDSMYu5Vv4_BMFHEGE6QKfw38PB4fC?usp=sharing)) (30 mins daily)
  - Choose a random question (many examples in this module in the “Extra Resources”)
  - If you know it great, answer it
  - If you don’t know it, great spend some time learning and writing down your learnings
  - Similar to coding questions committing to GitHub (to your practice repo) daily for the interview questions (make the git commit the name of the interview question)
